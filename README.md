# OOP in Dart – Library Management System

## About
This project is created for Dart Practice. It demonstrates Object-Oriented Programming concepts using a simple library system.

## Features
- Displays book details
- Represents library members and librarians
- Demonstrates borrowing a book
- Displays notifications when a book is added

## OOP Concepts Used
- **Classes and Objects:** Book, Person, Member, and Librarian
- **Constructors:** Initialize objects with values
- **Inheritance:** Member and Librarian extend Person
- **Mixins:** Notifier provides reusable notification behavior
- **Methods:** Display book details, borrow books, and add books

## Technologies
- Dart

## How to Run
1. Open https://dartpad.dev/
2. Copy the code from `main.dart` into DartPad.
3. Click Run to execute the program.
